# rezip

이미 압축되어 있는 ZIP 파일의 크기를 더욱 줄이겠다

## 사용 방법

```
Usage: rezip [OPTIONS] <FILES>...

Arguments:
  <FILES>...  

Options:
  -l <LEVEL>       [default: 264]
  -b <BUFFER>      [default: 1048576]
  -h, --help       Print help
```

## 처리 특성

- 최대 압축률을 위해 기본값은 Zopfli 레벨 264입니다. 입력 크기와 엔트리 수에 따라 처리 시간이 길어질 수 있습니다.
- 입력 ZIP은 작업 시작 시 디스크 기반 임시 스냅샷으로 복사합니다. 병렬 작업이 완료되면 최종 ZIP에 즉시 병합하지만, 원래 순서를 유지하기 위해 앞선 엔트리가 늦으면 뒤따른 완료 엔트리의 임시 ZIP이 대기합니다.
- 따라서 다수의 엔트리를 가진 대형 ZIP에서는 작업 중 임시 디스크 사용량이 입력 ZIP 크기에 근접할 수 있습니다. 완료 또는 실패 시 임시 파일은 자동으로 정리되며, 결과가 더 작을 때만 원본을 교체합니다.
